# Smart Prompt Edit · 高保真原型

小影科技 2027 校招 · AI 产品经理笔试 · Demo

> 把 AI Catch「Try This」的**整段复制**，变成**逐词替换**——用户不用碰那 600 个字符的英文提示词，只需要在标好的实体上点几下，就能产出自己想要的作品。

---

## 怎么跑

```bash
cd prototype
python3 server.py        # 默认端口 8788
```

浏览器打开 `http://127.0.0.1:8788/`

**零依赖**：只用 Python 标准库，不需要 `pip install`。

---

## 演示路径

```
首页 +  →  Text to Video  →  往下滑到 Explore（3 个真实生成的视频）
   →  点开一个  →  看到完整 Prompt  →  Try This
   →  Smart Edit：提示词里的实体被标出来
   →  点任意实体  →  底部弹出 LLM 候选 / 自定义 / 颜色
   →  Generate（1.5s 动画）→  首帧预览  →  生成视频  →  播放
```

**手机画面外有一个「一键应用真实替换」按钮**——点它会套用与改版视频完全对应的那几处替换，看到"改前 vs 改后"的真实差异。

---

## 重要说明

**当前版本未接入真实 VLM / 生成 API。**

- **界面文案、实体候选词**：真实产出（由豆包 Seed 2.1 Lite 提取与生成）
- **视频与首帧**：**预生成素材**（火山方舟 Seedream 4.0 + Seedance 2.5 实际跑出来的，共 12 条视频）
- 之所以改成预生成演示：真实生成一条 5 秒视频需要 2–3 分钟，不适合现场演示

后端仍保留了三条真实接口（`/api/ark/extract`、`/api/ark/frame`、`/api/ark/video`），填入 API Key 即可切换为实时生成。

## 设计还原依据

- **字体**：`Passion One Bold`，从 APK 里提取
- **主色**：`#8BFF43`，从真机截图做像素采样
- **版式**：按 1080×2400 真机截图换算成 390×844
- **界面**：全部来自实机操作录屏 + 截图，非臆想

---

## 原型包含的边界场景

| 场景 | 处理 |
|---|---|
| 自定义实体词超 10 个词 | 输入框实时截断 + 提示（`#scr-quickedit` 里的替换卡片） |
| 积分不足 | 不直接跳付费墙，先算清"还差多少"（`#scr-insufficient`） |
| 后端生成失败 | 明确告知，并在最显眼位置写"本次未扣积分"（`#scr-genfail`） |
